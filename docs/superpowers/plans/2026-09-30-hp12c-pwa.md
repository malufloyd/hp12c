**Goal:** Build an installable offline iPhone web app (PWA) that looks like an HP 12C Gold and behaves exactly like an HP 12C Platinum.

**Architecture:** Static site in vanilla ES modules, with no build step. ### Display state (produced by the engine, consumed by the UI)

```js
{
  text: string,        // LCD content, see "Display text" below
  ann: { f, g, begin, dmy, c, prgm, rpn, alg, paren },  // booleans
  running: boolean,    // show flashing "running"
  blink: boolean,      // overflow: display flashes until next key
  off: boolean         // calculator switched off → blank LCD
}
```

### Display text

The display text is a plain string that `lcd.js` renders cell by cell:
- Every character except `.` and `,` occupies one digit cell.
- `.` and `,` light the point/comma segment of the preceding cell.
- A leading `-` goes into the separate sign cell.
- A space is a blank cell.
- Numeric text is right-aligned in the 10 cells.
- Text that starts with a letter (`Error 5`, `Pr Error`, `running`, `P-08 r-20`, `SOUnd On`) is left-aligned.

Examples that tests use verbatim:
- FIX 2: `1,064.54`, `-13.54`, `0.00`.
- FIX 0: `15.`.
- SCI (mantissa, then a sign cell that is a space for a positive exponent or `-` for a negative one, then 2 exponent digits): `1.487456 01`, `1.000000-03`.
- Overflow: `9.999999 99`.
- PREFIX (mantissa): `1487456320`.
- Date result: `11,09,2004 6`.
- Program line: `001,     36`, `004,  42 25`, `008,43,33,000`.
- MEM: `P-08 r-20`.
- Errors: `Error 0` … `Error 9`, `Pr Error`.

### Test helper token language (`tests/helpers.js`, created in Task 3)

`run(calc, "58.33 ENTER 22.95 -")` splits on whitespace:
- A token matching `/^[0-9.]+$/` presses each character (`.` → 48).
- Every other token is looked up in `TOKENS`, which maps names to one or more key codes, e.g. `AMORT` → `[42,11]` and `12x` → `[43,11]`.
- An unknown token throws.
- `=` maps to ENTER (36).
- Bare `f` and `g` are prefix presses, so `f 4` means FIX 4.

```js
import Decimal from '../../vendor/decimal.mjs';

export const D = Decimal.clone({
  precision: 34, rounding: Decimal.ROUND_HALF_UP,
  toExpNeg: -200, toExpPos: 200, minE: -9e15, maxE: 9e15,
});
export const ZERO = new D(0);
export const ONE = new D(1);
export const HUNDRED = new D(100);
export const MAX = new D('9.999999999e99');
const MIN = new D('1e-99');

export function toD(v) { return v instanceof D ? v : new D(v); }
export function isInt(x) { return x.isInteger(); }

export function normalize(x) {
  if (!x.isFinite()) return { value: x.isNeg() ? MAX.neg() : MAX, overflow: true };
  if (x.isZero()) return { value: ZERO, overflow: false };
  const r = x.toSignificantDigits(10, D.ROUND_HALF_UP);
  if (r.abs().gt(MAX)) return { value: r.isNeg() ? MAX.neg() : MAX, overflow: true };
  if (r.abs().lt(MIN)) return { value: ZERO, overflow: false };
  return { value: r, overflow: false };
}
```

```js
import { D } from './engine/number.js';

function group(intStr) { return intStr.replace(/\B(?=(\d{3})+(?!\d))/g, ','); }
export function swapSeparators(t, commaDecimal) {
  return commaDecimal ? t.replace(/[.,]/g, c => (c === '.' ? ',' : '.')) : t;
}
function sci(x) {
  const neg = x.isNeg();
  let m = x.abs().toSignificantDigits(7, D.ROUND_HALF_UP);
  if (m.e > 99) m = x.abs().toSignificantDigits(7, D.ROUND_DOWN);   // overflow shows 9.999999 99
  const e = m.e;                                   // decimal.js exponent of first digit
  const mant = m.div(new D(10).pow(e)).toFixed(6);
  const exp = String(Math.abs(e)).padStart(2, '0');
  return (neg ? '-' : '') + mant + (e < 0 ? '-' : ' ') + exp;
}
export function formatNumber(x, { fix, sci: sciMode, commaDecimal }) {
  let t;
  if (sciMode && !x.isZero()) t = sci(x);
  else if (x.isZero()) t = fix === 0 ? '0.' : '0.' + '0'.repeat(fix);
  else {
    const a = x.abs();
    const intDigits = a.e >= 0 ? a.e + 1 : 1;
    if (intDigits > 10) t = sci(x);
    else {
      let d = Math.min(fix, 10 - intDigits);
      let r = a.toDecimalPlaces(d, D.ROUND_HALF_UP);
      const rInt = r.e >= 0 ? r.e + 1 : 1;
      if (rInt > 10) t = sci(x);
      else {
        if (rInt + d > 10) { d = 10 - rInt; r = a.toDecimalPlaces(d, D.ROUND_HALF_UP); }
        if (r.isZero()) t = sci(x);
        else {
          const [ip, fp] = r.toFixed(d).split('.');
          t = (x.isNeg() ? '-' : '') + group(ip) + '.' + (fp ?? '');
        }
      }
    }
  }
  return swapSeparators(t, commaDecimal);
}
export function formatMantissa(x) {
  if (x.isZero()) return '0000000000';
  return x.abs().toSignificantDigits(10, D.ROUND_HALF_UP).toFixed()
    .replace('.', '').replace(/^0+/, '').padEnd(10, '0').slice(0, 10);
}
export function formatEntry({ mant, exp, expNeg, neg }, commaDecimal) {
  let [ip, fp] = mant.split('.');
  if (ip === '') ip = '0';
  let t = (exp === null ? group(ip) : ip) + (fp !== undefined ? '.' + fp : '');
  if (exp !== null) t += (expNeg ? '-' : ' ') + exp.padStart(2, '0');
  return swapSeparators((neg ? '-' : '') + t, commaDecimal);
}
```

Prefix states handled inside `calculator.js`:
- `'f'`, `'g'`;
- `'STO'`, `'RCL'`, `'STO.'`, `'RCL.'`;
- `'STO+'`, `'STO-'`, `'STO*'`, `'STO/'`;
- `'RCLg'` (RCL g CFo/CFj/Nj);
- `'GTO'` with collected digits, `'GTO.'`.

Rules:
- Pressing `f` or `g` while the other is active switches the prefix.
- `f` or `g` again cancels.
- `f PREFIX` (f ENTER) cancels any prefix and sets `showMantissa` until `release()`.

Stack and entry rules (manual Appendix A):
- **Digit, `.` or `EEX`:**
  - If there is no entry in progress: if `lift` is true, lift the stack (T lost, Z←… , Y←X); then start an entry. Clear `finStored`.
  - Maximum 10 mantissa digits (further digits ignored).
  - `EEX` with an empty mantissa starts the mantissa at `'1'`.
  - Exponent digits: keep the last 2.
- **`CHS`:** during entry, before EEX, it toggles `entry.neg`; after EEX, it toggles `entry.expNeg`. Otherwise it negates X, with no lift change and no LSTx.
- **`ENTER` (RPN):** end the entry, copy X into Y (lift), set `lift=false`, clear `finStored`.
- **`CLx`:** end the entry, X = 0, `lift=false`.
- **`Σ+`/`Σ−`:** set `lift=false` (Task 13).
- **Any other operation:** ends the entry and sets `lift=true`.
- **Two-number ops:** drop the stack, with T duplicated into Z.
- **`x≷y`:** swaps X and Y. **`R↓`:** rolls the stack down (X←Y, Y←Z, Z←T, T←old X). **`LSTx` (g +):** in RPN, push lastX.
- **`STO r` / `RCL r`:**
  - `r` is a digit 0–9, `.` followed by a digit (registers 10–19), or n/i/PV/PMT/FV.
  - `RCL` pushes the value and clears `finStored`. `STO` into n/i/PV/PMT/FV sets `finStored=true`.
  - `STO` into a register that has been converted to program lines gives Error 6 (Task 14 provides `availableRegs()`; until then all 20 are available).
- **`STO + - × ÷ r`:** only for r in 0–4, otherwise Error 4. An overflowing result gives Error 1. `STO ÷` by 0 gives Error 0.
- **`STO EEX`:** toggles `mode.compound`.
- **`f 0`–`f 9`:** set `fix` and `sci=false`. **`f .`:** sets `sci=true`.
- **`finStored`:** set true by storing into or computing any of n/i/PV/PMT/FV (including `12x` and `12÷`). Set false by digit entry, ENTER, CLx, RCL, and any op that changes X. Left unchanged by prefix keys, `g BEG`/`g END`, `f FIX`/`SCI`, `g D.MY`/`M.DY`, and `STO EEX`.
- **Error handling:** a `CalcError` thrown by any op aborts it. The state is rolled back to the snapshot taken before the op and `state.error` is set.
  - While `state.error` is set, the next key press only clears the error and is otherwise ignored.
  - `ON` also clears it (Task 15).
- **Display text priority:**
  1. `off` → blank;
  2. `error` → `Error n` or `Pr Error`;
  3. `showMantissa` → `formatMantissa(X)`;
  4. PRGM mode → program line (Task 14);
  5. entry in progress → `formatEntry`;
  6. otherwise `formatNumber(X)`.

## Task 5: ALG mode (chain arithmetic, parentheses, =, percent)

**Files:**
- Create: `src/engine/alg.js`, `tests/alg.test.js`
- Modify: `src/engine/calculator.js` (route `+ − × ÷ yˣ %`, ENTER, `g =`, `g (`, `g )` and LSTx through `alg.js` when `mode.alg`), `src/engine/all-ops.js`

**Interfaces:**
- Produces: ops `rpn`, `alg`, `lparen`, `rparen`, `equals`, and `algBinary(calc, opName)`, `algPercent(calc)`.
- State: `state.alg = { acc: D|null, op: string|null, parens: [{acc, op}] }`.

Semantics (no precedence, left-to-right chain, per manual p.26):
- **Operator** (`+ − × ÷ yˣ`): end the entry. If `op` is pending: `acc = acc op X`, show acc in X; otherwise `acc = X`. Set `op` = new op and `lift = false` (the next digit replaces X). Clear `finStored`.
- **`=` (ENTER in ALG, or `g =`):** close all open parentheses left to right, then apply the pending op. X = result, `acc = null`, `op = null`. Then copy X into Y (Y = result) and set `lift=false`. That way `Δ%`, `%T` and `x≷y` see the previous result in Y.
- **`(`:** push `{acc, op}`, reset `acc=null, op=null`. More than 13 open parentheses → Error 4.
- **`)`:** evaluate the inner pending op (`acc op X`, or X if there is none), pop the outer `{acc, op}`, and set X = inner result, leaving the outer op pending.
- **`%` in ALG:** if the pending op is `+` or `−`, then X = acc·X/100; otherwise X = X/100. It does not complete the chain.
- **`Δ%` and `%T` in ALG:** use Y as the base, same formulas as RPN.
- **`LSTx` in ALG:** swaps X with lastX and never lifts.
- **`f RPN` / `f ALG`:** switch mode and reset `state.alg`.
- Functions (1/x, √x, TVM keys, etc.) act on X as in RPN.

## Task 8: Time value of money (TVM), 12×, 12÷, BEG/END, odd period, simple interest

**Files:**
- Create: `src/engine/finance.js` (TVM part), `src/engine/solve.js`, `tests/tvm.test.js`
- Modify: `src/engine/all-ops.js`

**Interfaces:**
- Produces:
  - `src/engine/solve.js`: `solveRoot(f: (r: D) => D, {lo, hi, guess}) → D | null`. It is a robust bracketed root finder: it scans outward from the guess for a sign change, then runs Brent/bisection until |Δ| < 1e-18 or 200 iterations. It returns null if no bracket or no convergence.
  - `src/engine/finance.js`: `tvmResidual(st, r) → D`; ops `n, i, pv, pmt, fv, 12x, 12div, beg, end, int`; and `finKey(calc, name)` implementing the store-vs-compute rule.

Store vs compute (manual p.41 footnote):
- If `state.finStored` is true, the key **computes** that register. Otherwise it **stores** X into it (ending the entry).
- Both store and compute set `finStored = true`.
- After a store, X keeps its value (and `lift = true`).
- A computed value goes to X (pushed, stack lift as a normal result: `calc.push(v)`).

TVM equation (r = i/100, S = 1 if BEGIN else 0; if n is not an integer: N = INTG(n), F = FRAC(n)):

```
A = (C on) ? (1+r)^F : (1 + r·F)       // A = 1 when n is an integer
v = (1+r)^-N
a = (1 - v)/r        (a = N when r = 0)
0 = PV·A + (1 + r·S)·PMT·a + FV·v
```

- **PV** = −((1+rS)·PMT·a + FV·v)/A
- **PMT** = −(PV·A + FV·v)/((1+rS)·a)
- **FV** = −(PV·A + (1+rS)·PMT·a)/v
- **n** (closed form, integer periods only):
  - When r ≠ 0: `k = (1+rS)·PMT/r`, `v = (PV + k)/(k − FV)`, and n = −ln(v)/ln(1+r).
  - When r = 0: n = −(PV+FV)/PMT.
  - Error 5 if v ≤ 0, the result isn't finite, PMT=0 with r=0, or i ≤ −100.
  - Rounding: if FRAC(n) < 0.005, round down; otherwise round up (manual p.50).
- **i:**
  - Error 5 if n = 0 or n ≥ 1E10 or n < 0.
  - Solve `tvmResidual(r) = 0` with `solveRoot` on r ∈ (−0.999999, 1e6), guess 0.01; Error 5 if null.
  - Result = r·100.
- **PV/PMT/FV:** Error 5 if i ≤ −100.
- **12×:** X·12 → n. **12÷:** X/12 → i. Both put the result in X (as a unary op) and store it.
- **BEG/END:** set `mode.begin`. **STO EEX (compound)** was already done in Task 3.
- **INT (f i):**
  - I360 = −PV·(i/100)·n/360 and I365 = −PV·(i/100)·n/365.
  - After the op: X = I360, Y = −PV, Z = I365 (three pushes: I365, then −PV, then I360).

Precision: do the internal TVM math at 34 digits; only the stored/displayed result is normalized to 10.

Algorithm (SIA / manual App. E, semiannual, actual/actual; verified to give 120.3795648 / accrued 2.6926229 for G1):
1. Parse both dates; Error 8 if invalid, maturity ≤ settlement, or more than 500 years apart.
2. Find the coupon dates by stepping back from maturity in 6-month steps with `addMonths(maturity, −6k)`. If any step returns null (the day doesn't exist in that month), Error 8. ## Task 14: Programming

**Files:**
- Create: `src/engine/program.js`, `tests/program.test.js`
- Modify: `src/engine/calculator.js` (the `recordKey` hook for program mode, and program-line display), `src/engine/all-ops.js`

**Interfaces:**
- Produces:
  - `recordKey(code) → boolean`.
  - `availableRegs() → number`.
  - `runUntilHalt(calc, maxSteps=100000)` (test helper; PSE doesn't wait).
  - `tick(calc, nowMs, budgetSteps=500) → boolean` (still running).
  - `formatLine(pc, codes) → string`.
  - Ops `pr, rs, sst, bst, pse, gto, xley, xeq0, mem, clrPrgm`.

Model:
- **Program storage:**
  - `prog.lines` is an array (index 0 = line 001) of instructions; each instruction is an array of key codes, e.g. `[36]`, `[42,25]`, `[44,40,1]`, `[43,33,12]` (GTO 012; the target is stored as one number).
  - Lines beyond `lines.length` up to `allotted` are implicit `GTO 000`.
- **Memory:**
  - `allotted = max(8, 8 + 7·ceil((lines.length − 8)/7))`, capped at 400. Keying a 401st line gives Error 4.
  - `availableRegs() = 20 − max(0, ceil((allotted − 260)/7))`. At 400 lines, 0 registers remain. Registers are lost from R.9 downward: register index `>= availableRegs()` is unavailable, so STO/RCL there gives Error 6.
  - `g MEM` shows `P-` + allotted padded to 2 digits (3 when ≥ 100) + ` r-` + available padded to 2, e.g. `P-08 r-20`.
- **Program mode (`f P/R`):**
  - `prgmMode` toggles, the PRGM annunciator shows, and `pc` is set to 0.
  - Key presses go through the same prefix decoder. When a complete instruction is formed, it is **inserted** after line `pc`, pc advances, and the display shows it.
  - Not recordable, and executed immediately in program mode instead: `f P/R`, `SST`, `g BST`, `g GTO . nnn` (moves pc), `f CLEAR PRGM` (clears all lines, pc=0), `g MEM`, `f PREFIX`, and `ON`.
  - Not programmable (ignored in program mode): `f CLEAR REG`, `g D.MY`, `g M.DY`, `STO EEX`.
  - Digit keys are separate instructions.
- **Line display:**
  - `formatLine(0)` = `000,` right-padded with blanks.
  - For others: 3-digit line number + `,` + the codes right-aligned in 7 cells. Codes are joined with a space and each is shown as 2 chars; a single-digit key code is `' d'`.
  - Exception: GTO is shown as `43,33,` + 3-digit target.
  - Examples: `001,     36`, `002,      2`, `004,  42 25`, `003,44 40  1`, `008,43,33,000`.
- **Run (`R/S` in run mode):**
  - Starts at pc (if pc = 0, it starts at line 1). Sets `prog.running = true`.
  - Each step executes the instruction at pc by feeding its codes to the normal dispatcher, then pc++.
  - Past `allotted`, or on reaching an implicit or explicit `GTO 000`: pc = 0 and stop.
  - `R/S` inside a program stops, with pc left at the next line.
  - `g GTO nnn` jumps.
  - `g x≤y` / `g x=0`: if the condition is false, skip the next line.
  - `g PSE` pauses about 1 s showing X (`waitUntil = now + 1000`).
  - Any error stops execution and shows the error.
  - Any key pressed while running stops it (the key is not executed).
  - The display shows `running` while running.
  - `g GTO nnn` in run mode (not while a program is running) sets pc.
  - SST in run mode: `press` shows the line at pc+1; `release` executes it and shows the result.
- **Mode rule:** programs execute in whatever mode is current; no enforcement is needed.
